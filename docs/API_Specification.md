# 콘서트 예약 서비스 API 설명서

##  개요

콘서트 예약 서비스를 위한 RESTful API입니다. 대기열 시스템을 통한 서비스 접근 제어, 좌석 예약, 결제 처리 등의 기능을 제공합니다.

### 1. 대기열 시스템
-  토큰 기반 인증 : 모든 API 호출 시 유효한 대기열 토큰 필요
-  FIFO 순서 보장 : 먼저 요청한 사용자가 우선 서비스 이용
-  동시 접근 제한 : 최대 100명의 사용자가 동시에 활성화 가능
-  토큰 만료 관리 : 설ㅈ정분 유효 기간, 자동 정리

### 2. 콘서트 및 좌석 관리
-  콘서트 정보 조회 : 날짜별, 제목별 콘서트 검색
-  좌석 상태 관리 : 실시간 좌석 상태 조회 (예약가능, 임시배정, 판매완료)
-  임시 배정 시스템 : 5분간 좌석 임시 배정, 자동 만료

### 3. 예약 및 결제
- 좌석 예약 : 임시 배정 후 결제 대기   
- 잔액 관리 : 충전, 조회, 거래 내역 추적
-  결제 처리 : 잔액 차감, 예약 확정, 토큰 만료
